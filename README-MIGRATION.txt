💡 常見問題速查
─────────────────────────────────────────────────────────────────────────────

Q: 登入失敗「無法取得使用者資訊」
A: profile 記錄缺失 → 見 ENSO-SUPABASE-MIGRATION.md 故障排除部分

Q: 購物金未發放
A: 檢查：referrer_id 綁定、tier 是否為 normal、訂單是否 completed

Q: npm 命令超時
A: 正常（項目大）→ 等待編譯或清除緩存 rm -rf node_modules/.vite

Q: TypeScript 錯誤
A: 運行 npm install，然後重啟開發服務器
